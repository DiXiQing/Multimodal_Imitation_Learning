Function / MLP 100f / LSTM 5f. Input: index_mcp_object_distance_mm (Euclidean landmark 5 to object). Output: finger_width_mm.
400 fixed neural epochs; final epoch saved. Function single Train-only fit; no epoch selection or Test tuning.
Aperture plots and error metrics use mm; distance ratio and R2 are dimensionless, actual elapsed seconds, original frame IDs. MLP: last 100 distances, short history left-padded with first real input; main metrics start at 5 real frames. LSTM: independent rolling window up to 5 frames, zero state each window; short prefixes use available frames. Physical input x=distance_mm/first_recorded_distance_mm (first=1); no secondary input scaling. scaled_y=(aperture_mm-y_mean)/y_std fitted on Train only. Predict mm=scaled_output*y_std+y_mean. Distance divided by first recorded distance; no time or aperture normalization.
Main metrics use common valid 5-frame targets for all models. Separate LSTM rolling-5 exports start at first valid frame, resetting on missing/invalid rows and frame/time gaps.
Train and Test reports include overall and per-experiment scores. Train MAE history is measured during training with dropout active; final Train metrics use evaluation mode.
Original data preserved; split_manifest.json records whole-experiment partition.
