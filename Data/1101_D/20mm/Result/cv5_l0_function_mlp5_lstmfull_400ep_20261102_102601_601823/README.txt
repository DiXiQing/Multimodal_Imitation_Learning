5-fold trial-level cross-validation. Each complete trial is held out once, using the same fold for Function, MLP 5f and LSTM Full. Main report: oof_mean_sd.csv and test_model_comparison_mean_sd.png (per-trial MAE/RMSE/R2 mean and sample SD across held-out trials, not SD across five fold averages).
Each fold trains fresh models, fits output numeric scale on Train only, and fits Function on Train only with fixed lambda. Neural models train exactly 400 epochs and save the last epoch; Test never selects parameters or epochs.
Input: index_mcp_object_distance_mm / its first recorded value, dimensionless l/l0; input scaler identity. Target: finger_width_mm. No time normalization, aperture amplitude normalization, smoothing, velocity or future inputs.
MLP waits for five real consecutive inputs. LSTM uses the full continuous causal history, reset at trial start or invalid/frame/time gaps; initial distance baseline retained across gaps. All main losses and metrics use identical valid frames. Separate LSTM-from-start predictions include early valid frames.
OOF contains held-out predictions only. Each fold contains Train/Test diagnostics, training curves and three final models. Train results are not the reported cross-validation score. There is no single final model trained on all trials.
Trials are read in place; backup, review_segments, derived folders and existing Train/Test directories are excluded. Original data unchanged. Similarity selection preceded this evaluation; results describe the selected trials.
