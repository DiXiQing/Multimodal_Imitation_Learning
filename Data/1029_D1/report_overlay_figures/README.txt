Three separate figures in each subfolder: 20, 30, 40 mm, 100 trials each.
Axes: l = Euclidean landmark-5-to-object distance; d = finger aperture. millimetres/: l in mm, d in mm. initial_distance_normalized/: l/l0, d in mm; l0 from first recorded frame.
Colour: actual time from annotated action onset to five-frame closure confirmation, excluding 10-frame pre-roll and post-hold margins; all three figures share a colour range. This is an operational duration, not a direct physical-contact sensor measurement.
Plots use the same Train + Test trials used for the models (one copy of each trial); backup/derived folders excluded. Raw measurements, no smoothing/interpolation or time normalization.
User confirmed physical object sides 20/30/40 mm and all scales measured using a 30 mm reference block. Original calibration and CSV fields unchanged.
