# 蓝／红／黑三个目标的 5 帧 MLP 实时实验

在 gripper 环境运行：

```powershell
python New/Program/inference_three_targets_mlp.py
```

脚本顶部 `MODEL_PATHS` 已填写三个最终模型：蓝色 3 cm、红色 2 cm、黑色 4 cm。更换时修改对应绝对路径，或使用 `--blue-model`、`--red-model`、`--black-model` 参数。三个模型分别使用各自保存的归一化和检测参数，不重新训练。

## 操作

1. 每次只放一个目标，后续三个目标轮流放在同一区域。保持相机、照明、分辨率和帧率与训练时一致。
2. 启动后画面保持实时更新，用鼠标拖框选择物体放置区域，按 Enter 或空格确认。框比最大目标稍大，留出边缘；避开红色标记、黑色袖口和其他物体。Q / Esc 退出。
3. 按一次 N 开始整场连续录制，可以在尚未放入物体或检测到手之前开始。
4. 蓝、红、黑目标每次放入一个，按实验顺序连续完成共 9 次抓握。中途换目标无需停止录制。连续 3 帧同色才确认，再积累 5 帧距离预测。
5. 全部完成后按 S 保存整场，或 Q / Esc 保存退出。

其他按键：R 重新框选放置区域，M 看检测掩膜，L 锁定／解锁当前物体中心。R 和 L 只能在未录制时操作。默认每帧检测物体中心，与原实时脚本一致。

## 实时检测参数

启动后另外显示中文参数窗口，含蓝色、红色、黑色三个页面；页面仅选择要调整的参数，不会指定识别结果或模型。

- 黑色：亮度上限 V、饱和度上限 S、最小面积。
- 红色／蓝色：饱和度下限 S、亮度下限 V、各自的最小面积。
- 勾选“显示当前调参颜色的掩膜”，可在预览中单独查看该颜色筛出的像素。
- 每页可以滚动，且有“恢复该颜色的模型默认参数”。关闭参数窗口会保存当前实验并结束推理。

滑块实时生效，变化时清空历史窗口和中心锁定。建议先在预览中调好，再开始正式录制。若录制中调整，逐帧 CSV 的 `parameter_revision` 与运行目录 `detection_parameter_events.json` 会记录参数变更，试次配置也保留开始时的参数。

修改后的参数自动保存到 `New/Program/inference_three_targets_detection.json`，下次启动读取。模型权重和模型原始参数不变。可用 `--detection-settings "绝对路径"` 使用独立参数文件，`--no-controls` 隐藏参数窗口；`--no-preview` 模式也不创建参数窗口。

若黑色时出现红／黑候选冲突，先查看红色掩膜并适当提高红色最小面积，确认小红色干扰区域被排除，同时真实红色目标仍能识别；调黑色亮度不能直接消除红色候选。

颜色由框内的 HSV 检测决定，不由实验顺序决定。框内多个颜色候选或无候选时不猜测目标，也不默认选择黑色。它用于当前三个已知物体，不能视为任意物体分类器。

预览和录制时都自动切换模型，切换、漏检或时间间隔过长会清空历史窗口。不同模型不会共享距离窗口。无物体、颜色冲突和预热期间继续保存视频和 CSV，预测留空。冲突时仍显示所有颜色候选框及颜色、尺寸、边框面积，CSV 的 candidate_details 保存对应位置。边框面积不是形态学前的像素面积。

预测仍使用过去 4 帧加当前帧的距离，输出当前指间距；不额外平滑，不使用真实指间距作为输入。

## 结果

保存路径仍为 `Data/TopView/Inference/run_时间戳/`：

- `trial_001/` 等：每个文件夹是一场连续录制，保存原始视频、预测视频、逐帧 CSV、整场对比图、MAE/RMSE/R² 汇总及配置；不再等同于一次抓握。
- `trial_metrics.csv`：每场录制按选中目标颜色分组的模型路径、预测覆盖率、MAE、RMSE、R²；不是逐次抓握指标。覆盖率以已确认该颜色的帧为分母，不包括未确认颜色的帧。
- `target_metrics.png`：按目标分组的录制场次指标均值；不包含预览帧。
- 根目录 `predictions.csv`：整场记录，包含检测颜色、选择的模型、试次绑定颜色、窗口内容、预测和状态。根目录 summary 含预览帧，实验分析优先使用逐试次结果。

`trial_target_color` 保留旧列名兼容性，但现在随当前确认颜色变化；不是独立人工真值。计算识别准确率时需另按视频或实验顺序核对实物颜色。自动选择错误也应保留，不要只汇总识别成功的实验。

脚本不生成随机顺序：预实验可先每种 3 次，按每轮三个目标各一次、轮内随机更换。默认代码仅负责识别、选模型和录制。

可指定放置区域免去鼠标框选，例如（坐标需按你的实际画面设置）：

```powershell
python New/Program/inference_three_targets_mlp.py --roi 240 190 130 130
```

新文件复用 `inference_window_mlp.py`、`inference.py` 和原录制脚本中的函数，请保持这些文件在同一目录。

连续录制不会自动判断恰好发生了 9 次抓握，也不会自动切成 9 个片段；换颜色次数不等于抓握次数。需要逐次分析时，应在保存后另外分段。
